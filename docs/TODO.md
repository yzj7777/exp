## 完成定义（Definition of Done）

- [ ] 有一个清晰聚焦的目标用户和真实场景。
- [ ] Agent 能根据用户回答自适应追问，而非只按固定问卷运行。
- [ ] Agent 能发现至少一类歧义/缺失/冲突，并向用户确认。
- [ ] 需求状态、依据和未决问题可追溯。
- [ ] 用户可修正回答，需求文档会相应更新。
- [ ] 输出包括结构化需求、范围、未决事项和可验证验收标准。
- [ ] Demo 可按说明运行，异常和隐私边界有明确处理。
- [ ] 项目通过测试，具备可复现案例和效果评估。
- [ ] 正式项目文档和可现场交互的展示网页齐备；已向官方核实网页展示方式符合提交要求。
- [ ] 已按官方最新通知完成合规和提交核验。
