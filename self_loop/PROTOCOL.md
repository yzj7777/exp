# SelfLoop 固定提示词（每轮迭代原样执行，永不漂移）

你现在处于无限研究循环中的一轮。课题记录在 `self_loop/state/TODO.md` 标题的"课题原文"中，
**唯一事实来源是磁盘状态**：`self_loop/state/TODO.md`（开放问题队列）、`PROGRESS.md`（已验证发现）、`ITERATIONS.md`（日志）。

## 每轮执行（严格按序）

1. 运行 `bash self_loop/tick.sh`，加载本轮固定视图（迭代号 / 下一个问题 / 最近发现）。
2. 取 TODO.md「## Open questions」里第一个未勾选问题。若 TODO 为空但你判断课题**未真正挖完**，先补充 2-3 个新子问题再取一个。
3. 研究：每轮至少 1 次 `web_search`（depth 1-2 视需要）；关键结论需 ≥2 个独立来源交叉验证，必要时 `fetch_page` 读原文。
4. 把**已验证**发现追加进 `PROGRESS.md`：新块 `## [iter N] <你回答的问题>` + 来源 URL。未验证内容必须标注 `(unverified)` 或 `(inference)`。
5. 更新 `TODO.md`：勾掉已回答的（行尾注明 iter 号），加入新发现的跟进问题。
6. 往 `ITERATIONS.md` 追加一行：`## Iteration N — <做了什么> | 新发现: 是/否`。
7. **饱和判定**（满足其一才允许停）：
   - TODO 为空 且 确实想不出有价值的新子问题；
   - 连续 2 轮 `新发现: 否`（信息不再增长 = 已挖到该来源体系的极限）。
   停止时写 `self_loop/state/REPORT.md`（综合报告 + 全部来源 + 未解问题），然后结束。
   否则：**立即自动开始下一轮**，无需任何人输入。
8. 回合边界：接近本回合上下文极限、或每完成 3 轮时，结束本回合，用 `ask_user` 给出
   【继续挖下一轮】【停止并写报告】【换方向】。

## 铁律

- **禁止空转**：不得重复研究 PROGRESS/TODO 已覆盖的问题；若本轮搜索只能复述已有内容，立即换问题。
- 不编造来源；搜不到就记 `(not found)` 并换角度再试一次，仍无则记入未解问题。
- 循环的终点是**信息饱和**，不是上下文爆炸 —— 上下文快满时滚入新回合，磁盘状态无损。
- 修改 state 文件用追加/勾选，不要重写历史块（保留审计轨迹）。
