# 自测：能力 / 降智探针（2026-10-16）

## 做了什么
- `gen.py`：用固定随机种子（`20261016`）生成 15 道可以客观判分的题，包括 4×4 位乘法、模幂、字母计数、星期推算、排序、字符串反转、区间素数计数、布尔求值、进制转换，以及在约 10KB 文本里找隐藏的 8 位码和它所在的行号。
- 答题时**不用任何代码或工具**，全靠心算推理，答案写在 `my_answers.json` 里；只有大海捞针那题用 `read_file` 读了一遍文件（没有用 grep）。
- `grade.py`：拿 Python 算出的标准答案判分。

## 结果
**15/15 全对**，复现方法：`python3 selftest/grade.py`

## 这个测试能说明什么、不能说明什么
- 能说明：这个会话里的模型多步算术、计数、长文本检索和指令执行都正常，没有明显「降智」。
- 不能说明：
  - 出题、答题、判分都是同一个模型，题目又偏简单，属于**弱证据**，不能代替盲测。
  - 测不出**模型身份或型号**，也测不出**参数量**。闭源模型不公开参数量，前面那份工具调研里没有一个黑盒工具能可靠估算参数量。指纹工具只能把模型归到它指纹库里最像的那一个。
  - 测不出**量化**：前面的调研结论是，只看文本输出基本测不出量化，需要 logprobs 或参考部署。

## 想自己做更严格的盲测
从 [ModelTrace 的 GitHub Pages 手动版](https://github.com/xqy2006/ModelTrace) 复制挑战题，在新会话里发给待测模型，再把输出粘贴回去；也可以把 `gen.py` 换一个种子生成新题，在新会话里让模型作答后用 `grade.py` 判分。
